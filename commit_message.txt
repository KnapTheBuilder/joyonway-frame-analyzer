V4.2 - EN / FR language switch with localStorage persistence

ADDED
- Floating top-right pill (cyan, FR | EN) for bilingual UI. Default
  language is FR (matches the analyzer's primary author language).
  Selection persists across sessions via localStorage key
  joyonway_lang.
- Full bilingual coverage of static UI strings: card titles, dropzone
  text, contribute card, stats labels, B4 decode labels, footer.
- Dynamic content translation: Contribute status messages (waiting,
  sending, success, canceled, disabled, error), input placeholders,
  alert boxes, evolution messages between first and last B4 broadcast.
- MutationObserver with 80 ms debounce automatically translates DOM
  changes injected by analyzer rendering (stat boxes, tables, decode
  grids) when the user is in EN mode.
- Per-node WeakMap cache preserves original text on first translation
  to allow lossless FR <-> EN round-trips without flicker.

CHANGED
- Version pill, footer text, and page title bumped to V4.2.
- All inline strings in render functions remain in FR (the canonical
  language). The i18n layer translates them at runtime when EN is
  selected.

Tested: FR <-> EN switching on Chrome, Safari iOS, Firefox. Default
FR loads correctly on first visit. Switching to EN persists across
page reload.
