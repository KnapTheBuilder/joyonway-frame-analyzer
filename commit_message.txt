V4.2 - Full V4.0+V4.1+V4.2 in single standalone docs/index.html

This commit consolidates all V4.x features into a single self-contained
docs/index.html file (34 KB, no external dependencies):

V4.0 BASE
- Drag and drop file upload
- P23B32 frame extraction (1A...1D delimiter with 1B XX pseudo-escape)
- B4 broadcast decode: water temp, setpoint, filtration, heater, bubbler
- Statistics, distribution chart, tabs by CMD type
- Consigne (setpoint) highlighting in A1 frames
- Suggestions module

V4.1 ADDITIONS
- Multi-format upload: auto-detect binary vs text content
- Accepts .bin (raw bytes), .txt / .log / .cap / .hex (hex text, xxd output,
  raw hex, hex with spaces / commas / 0x prefix)
- Comment lines starting with # are ignored
- Heuristic: 512-byte sample, >=85% printable ASCII or whitespace -> text mode
- Contribute card with opt-in checkbox (checked by default)
- Anonymous JSON payload to ha-joyonway-multi project endpoint
- Optional fields: declared controller model, declared keypad model,
  capture context (500 chars max)
- 3-second debounce allows user to uncheck before send
- Payload truncation at 100 KB hex (50 KB raw data)
- Webhook URL configurable via CONTRIBUTE_WEBHOOK_URL constant
  (empty value = disabled, UI visible but inactive)
- Failure-safe: capture always analyzed locally regardless of send result

V4.2 ADDITIONS
- Floating top-right pill (cyan, FR | EN) for bilingual UI
- Default language is FR (matches the analyzer's primary author language)
- Selection persists across sessions via localStorage key joyonway_lang
- Full bilingual coverage of static UI strings: card titles, dropzone text,
  contribute card, stats labels, B4 decode labels, footer
- Dynamic content translation via MutationObserver with 80 ms debounce
- WeakMap cache preserves original FR text per DOM node for lossless
  FR <-> EN round-trips without flicker
