Workflow
  1. If you know your controller (P23B32, P69B133...), select it. Otherwise use Scan all delimiters first to identify it.
  2. Disable any active HA Joyonway integration (only one TCP client at a time on the W610)
  3. Capture RS485 traffic: timeout 60 nc <W610_IP> 8899 | xxd > capture.txt while changing spa state (setpoint, pumps, filtration)
  4. Upload the capture. The tool extracts frames using your selected format.
  5. Mark a frame as reference, then click another frame in a different state — bytes that differ are highlighted in red
  6. Byte Position Statistics shows which positions vary across all frames of the same Src/CMD pair
Adding new presets: edit the FORMATS object in the source (or open an issue at the repo with your model and frame structure).
